# Source lineage

This public Nebius source release starts from the reviewed Together local-install rc3 source, commit `b85564d8032822f385c7b0b41bc36e97ed75740e`. It has a fresh public Git history; private installation histories and receipts are not bundled.

The earlier recording-source commit was `316ea1e59e686e75011186559d9d84f2335da87c`. That extends verified local runtime `a3a1f2e824be060eac58fd5e29f952861cf8df8e`, derived from earlier Together source `acfc9aa6feb3ea63cca7c75b774ce0cf8a499091`.

This rc3 follows private install rc2 `811506babe84994c202c2540a412f76cb5a1e513` and rc1 `f96292cf86abee8e13a500aef055d26b7baa9998`. It addresses the independent first-use trial’s navigation, live-update, participant-display, CLI and documentation findings; it preserves the frozen exercise and original attribution. Rc3 adds view-only claim-expiry clarity and explains that one agent reply can use multiple model requests.

Multiple agent contributors worked on that source. Older work-unit identifiers in regression filenames describe its history; they are not provider requirements or an active orchestrator. Their coverage is retained. This package does not claim that the local application was written from scratch or by one model.

The installation changes add documented local agent setup over existing enrollment/MCP, automatic adapter preparation, free-port discovery and a clearer first-use path. The source manifest identifies the included bytes. Runtime, private credentials/conversations/trial receipts, Git history, recordings and design-reference images are excluded.

Earlier hosted deployment reports and retired Sites packaging remain preserved in the original source archive/history, outside this focused local distribution. Some hosted adapter sources and configuration fixtures remain because regression tests import them; they are not local setup steps or proof of deployment.

The separate recorded model trial retained an unknown transport request and a code check with nine passes and one failure. This source package contains none of that project’s private state and does not present its outcome as a new installation result. Fresh-user installation observations are reported separately.

The public packaging changes documentation, repository metadata and version only; application source and frozen exercise bytes remain the reviewed rc3 implementation. The MIT license, dependency inventory and generated-artwork provenance are retained. `private:true` protects against accidental npm publication; repository visibility is a separate GitHub setting.
